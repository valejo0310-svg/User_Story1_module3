# Training 1 - Interactive System 🫆
## 🔆Description

Simple interactive survey made with HTML, CSS, and JavaScript.
The program asks the user for their name and age, validates the inputs, and shows a message depending on the age.

----------------------------------------------------------------------------------------------------------------

## 🔆 Technologies
- HTML5
- CSS3
- JavaScript

________________________________________________________________________________________________________________

## 🔆 How to run
- Have an enviroment to run the code
- Clone or downland the .Zip for this repository
- Click right on the HTML doc and press the "Open with live server" option
- Enjoy

----------------------------------------------------------------------------------------------------------------

## 🔆 How It Works
- Click the Start button.
- Enter your name.
- Enter your age.
- The program validates the information.
- An alert message is displayed depending on the age.
